## 前言
是的，孩子们，我也去玩openclaw了。  
> 滴滴，正在打上保健品优质客户标签

{% image "https://img.antares.xin/assets/claw/6.webp", "openclaw" %}

说实话，其实我蛮早就关注小龙虾了，但是一开始都没去搞，主要是我感觉这玩意儿虽然看起来挺好玩，但是实际上并没有什么实质性的作用。最主要的原因就是太烧token，太费钱了，但是产出的东西……也就那样，没有发生根本性的变革，投入产出完全不成正比。

{% image "https://img.antares.xin/assets/claw/5.webp", "openclaw" %}

> 所以在这波小龙虾热潮里，真正的受益者真就是只有卖课的和卖token的。

至于我为什么在这几天突然玩小龙虾去了呢，主要是因为deepseek v4真便宜啊，v4 pro 缓存命中就几分钱。这下不得不玩了。
（虽然但是，我还是要提一嘴，deepseek便宜归便宜，但是也架不住openclaw疯狂烧啊，我玩了一天下来花了40多。不过这确实也和我跑的东西比较废token有关系。）

## 我拿小龙虾干了什么
还是从一开始的部署来讲吧，其实龙虾现在的部署已经是蛮简单的了，用一键安装脚本，输入必要的信息，然后就可以用了。  
`curl -fsSL https://openclaw.ai/install.sh | bash`  
{% image "https://img.antares.xin/assets/claw/1.webp", "openclaw" %}  
我用于部署openclaw设备是一台先前租的位于新加坡的腾讯云的服务器，命令输入后它会自己检测运行环境，下载必要的依赖。等它装完依赖之后会问你要ai的api，我这边准备的是deepseek的api，在它下面的选项里选择deepseek再输入api key即可。模型的话也会自动识别，最近v4 pro打折嘛，那么还是先选择用v4 pro。  
之后就是让你装一些什么skills之类的，我随便装了几个，有些还不能用，因为我懒得去配（bushi）。我觉得比较重要的skill就俩，一个是skill-vetter-v2 — 安全审查，另外一个是self-improving-agent-next — 持续改进。  
哦对，提一嘴，因为我这个服务器位于新加坡，在选择信息搜索api上我只需要选择duckduckgo的免费api即可，这也是用境外服务器的一个好处吧。  
我这边接入的是QQ机器人，现在的QQ机器人接入openclaw很方便，只要拿个QQ扫个码，不需要填什么回调地址，也不需要添加白名单。就有一个问题，如果想给别人用似乎只能给私聊的权限，不能拉进群里一起用，这点还是有点麻烦的。  
好了，那么回到最初的问题上来，我拿小龙虾干什么呢？eve online 这个游戏又被戏称为太空excel模拟器，官方的esi接口允许你从外部应用去调取游戏内的数据，例如市场上某个商品的价格，玩家机库里的物品（需要用户手动授权才能看到），军团的市场单等等等等。那么我能不能搞一个ai，让它去每天获取市场上的价格，然后告诉我近期生产什么产品利润最高，哪些产品的价格位于上行周期可以增产，哪些产品位于下行周期，需要减产或停产。    
就……eve不愧是eve，我真找到了个eve esi的mcp  
[大佬的项目](https://github.com/WaterPistolAI/EveOnlineMCP)  
{% image "https://img.antares.xin/assets/claw/2.webp", "openclaw" %}    
你还点评上了  
{% image "https://img.antares.xin/assets/claw/3.webp", "openclaw" %}   
之后的内容说简单也简单说麻烦也麻烦，总的来说就是让ai自己去装上这个mcp服务器，然后和它一起解决问题。  
总之，在烧了我十块钱之后，所有的功能都能正常使用了。  
## 总结
最后写个总结吧。小龙虾好用吗？好用！他能自己成长，能从前面的错误里吸取教训。  
（你可以让他总结问题，汇总成skill，之后就不怎么会犯错了）  
但是，这玩意儿太费token，太贵，就算是deepseek v4接近90%的缓存命中率，缓存命中后几分钱的成本，在部署阶段就花了我十块，后面让他帮我算利润那成本更是高的飞起。  
（计算利润需要先去获取蓝图，然后根据蓝图去查找每个原材料的价格，再加上星系成本指数，最后查找产品的销售价格，再刨去销售税，任务其实是蛮复杂的）  
我也尝试了让他总结为skill，或是将用过的命令保存下来下次复用，但是单次查询利润的成本还是要五毛钱左右，那我还不如自己打开网站去查一查价格哩。  
{% image "https://img.antares.xin/assets/claw/4.webp", "openclaw" %}   
以上就是我近期玩小龙虾的真实体验吧，过几天再去看看能不能找到点token来白嫖下，笨点就笨点吧。
