## 碎碎念
这个服务器里我搞的东西也就是AE2这一块，其他部分都是我朋友在负责的，我感觉我在游戏里就是个弱电工，这边扯一根网线，那边拉一条宽带……我是第一次玩AE，一开始这个线扯得跟蜘蛛网一样，纯粹的屎山，我自己都快要看不懂了，就是那种你随便在线上接个啥设备，大概率要瘫痪的那种，现在总算是搞出无线了，稍微好了点，至少能看得下去了。  
{% image "https://img.antares.xin/assets/atm10air/01/9.webp", "服务器截图" %}
这个服务器是我在9月11日开始开的，到现在也是快一个月了，一开始其实也是因为其他游戏玩腻了，来换换口味玩玩mc养养老。我们也确实做出来不小的成就，空岛越来越大，机器越来越丰富，某一天晚上的人数峰值竟然高达8人。MC好玩归好玩，但是这也是暂时的一股儿劲儿，这股劲儿过去了，也就有点“凉了”，我在做完AE2之后，也突然的不知道接下去做什么好了。
{% image "https://img.antares.xin/assets/atm10air/01/3.webp", "服务器截图" %}
说起来，我开过的类似这种整合包服，大概也是有十几个了，每次的寿命差不多也是在一个月上下，倒也不是说是不好玩，就是总是玩着玩着就没了继续玩下去的动力了。或许是因为小的时候没什么东西玩，所以那个时候才会这么沉迷MC，看别人的实况也能一看一集一小时。现在玩的东西多了，能够选的多了，反而发现自己越来越挑食，这个玩不下去，那个没有意思……
